Datenschutzerklärung

DNS64 Browser Extension · Version 1.4.4 · Stand: 7. November 2026

Die Erweiterung ist ein Client für eine selbst betriebene Node64-Instanz. Sie betreibt keinen eigenen Server, legt keine Konten an, enthält keine Werbung, keine Analyse und keine Telemetrie. Es gibt keinen Empfänger von Daten außer der Node, deren Adresse der Nutzer selbst einträgt.

Verantwortlich für die Verarbeitung ist der Nutzer selbst: Er betreibt die Node, in der die Daten ankommen. Der Entwickler der Erweiterung erhält keine Daten und hat keinen Zugriff darauf.

Welche Daten verarbeitet werden

DatumWoZweck
Adresse der Node, z. B. http://192.168.1.4:8080lokal, chrome.storage.localZiel der API-Aufrufe
API-Schlüssel der Nodelokal, chrome.storage.localAnmeldung an der Node (Authorization: Bearer …)
Einstellung Hell/Dunkellokal, chrome.storage.localDarstellung von Popup und Einstellungsseite
Zeitpunkt eines abgelehnten Schlüsselslokal, chrome.storage.local15 Minuten Pause, damit die Node nicht sperrt
Hostname des aktiven Tabsnur im Arbeitsspeicher, solange das Popup offen istSperrstatus dieser Domain anzeigen

Der Hostname wird nicht gespeichert und nicht protokolliert. Er wird als Suchbegriff an die Node gesendet, um deren Abfrage-Log nach dieser Domain zu durchsuchen, und beim Freigeben oder Sperren als Domain-Eintrag an die Node übergeben.

Keine Erhebung von Namen, E-Mail-Adressen, Standortdaten, Kommunikationsinhalten, Gesundheits- oder Finanzdaten. Keine Profile, keine Auswertung des Nutzungsverhaltens.

Wohin Daten gehen

Ausschließlich an die Node-Adresse, die der Nutzer einträgt – bei der üblichen Einrichtung ein Gerät im eigenen Netz. Der API-Schlüssel geht als Header an genau diese Adresse, der Hostname des aktiven Tabs als Suchparameter. Weitere Empfänger gibt es nicht; es werden keine Daten verkauft, nicht an Dritte übertragen und nicht zur Kreditwürdigkeitsprüfung verwendet.

Speicherung und Löschung

Die Angaben liegen im lokalen Speicher des Browserprofils, werden nicht synchronisiert und nicht gesichert. Löschen: Erweiterung entfernen oder die Felder auf der Einstellungsseite leeren. Kopien bleiben keine zurück. Daten in der Node verwaltet der Nutzer dort selbst.

Berechtigungen

  • storage – die oben genannten Angaben lokal speichern
  • alarms – das Abzeichen am Symbol einmal pro Minute aktualisieren
  • activeTab – nach Klick auf das Symbol den Hostnamen des aktiven Tabs lesen
  • http://*/*, https://*/* – Zugriff auf die frei wählbare Node-Adresse

Die Erweiterung liest keine Seiteninhalte, injiziert keine Skripte in Webseiten, legt keinen Verlauf an und lädt keinen Code aus dem Netz.

Kinder

Die Erweiterung richtet sich nicht an Kinder und erhebt wissentlich keine Daten von Kindern.

Änderungen

Änderungen dieser Erklärung erscheinen mit einer neuen Version der Erweiterung; das Datum oben wird angepasst.

Privacy Policy

DNS64 Browser Extension · Version 1.4.4 · Last updated: 7 November 2026

This extension is a client for a self-hosted Node64 instance. It runs no server of its own, creates no accounts, contains no ads, analytics or telemetry, and sends data to nobody except the node whose address the user enters.

Controller. The user is the controller: they run the node that receives the data. The extension developer receives no data and has no access to it.

Data processed. Node address, node API key, theme preference and the timestamp of a rejected key are stored locally in chrome.storage.local, only to talk to the node the user configured. The hostname of the active tab is held in memory while the popup is open, to show the blocking status of that site and to set or remove a domain on the node's allow/deny list; it is not stored and not logged.

No names, email addresses, location, communications, health or financial data. No profiling.

Recipients. Only the node address entered by the user – typically a device on their own network. The API key is sent there as an Authorization: Bearer header, the hostname as a query parameter. Data is not sold, not shared with third parties and not used for creditworthiness.

Retention and deletion. Data lives in the browser profile, is not synced and not backed up. Removing the extension or clearing the fields on the options page deletes it. Data held by the node is managed there by the user.

Permissions. storage (local settings), alarms (refresh the toolbar badge once a minute), activeTab (read the active tab's hostname after a click on the icon) and host access to the user-configured node address. No page content is read, no script is injected, no history is built, no remote code is loaded.
